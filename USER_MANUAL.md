# 📘 User Manual - CivicFix AI

Welcome to **CivicFix AI**, an intelligent civic complaint management system that allows users to report and track public issues easily.

---

## 🏙️ Overview

CivicFix AI helps citizens:
- Report civic issues
- Track complaint status
- Upload images as proof
- View complaint history

Admins can:
- View all complaints
- Update complaint status
- Manage civic issues efficiently

---

## 🚀 How to Use the System

---

## 👤 1. Registration

1. Open the application
2. Click on **Register**
3. Enter:
   - Username
   - Password
4. Click **Register**

✔ Your account will be created as a *Citizen*

---

## 🔐 2. Login

1. Enter your username and password
2. Click **Login**
3. You will be redirected to the dashboard

---

## 📝 3. Submit a Complaint

1. Go to **Submit Complaint Page**
2. Fill in the details:
   - Name
   - Location
   - Issue description
   - Category (auto-detected or manual)
   - Upload image (optional but recommended)
3. Click **Submit**

✔ Your complaint will be saved with a unique ID

---

## 🔍 4. Track Complaint

1. Go to **Track Complaint Page**
2. Enter your **Complaint ID**
3. Click **Track**
4. View:
   - Status (Submitted / In Progress / Resolved)
   - Category
   - Priority
   - Uploaded image

---

## 📊 5. Dashboard

- View all complaints summary
- See analytics and charts
- Understand complaint trends

---

## 🛠️ 6. Admin Panel (Admin Only)

1. Login using admin account
2. Open **Admin Panel**
3. You can:
   - View all complaints
   - Update complaint status
   - Manage resolution workflow
